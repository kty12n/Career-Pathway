# S.T.E.P Career Pathway

A responsive, static website for a career-readiness pathway. It is ready to upload to GitHub and publish with GitHub Pages.

## Run locally

Open `index.html` in a browser. There is no build step or installation needed.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload every file in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.

GitHub will show the public site address when deployment finishes.
